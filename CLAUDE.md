# Spartan Docs

The public API reference at docs.spartansystems.us: static files on GitHub Pages, no build. Read `README.md` for
how the pieces fit.

- `openapi.json` is generated by `scripts/sync-spec.py` from spartan-api's `GET /api/v1/openapi.json`. Fix wording
  at the source (the attributes on the action in spartan-api, or `guide.md` here), not in `openapi.json`.
- Every claim in `guide.md` (limits, headers, error bodies, schedules) must match spartan-api's code:
  `ApiUsageMiddleware`, `ApiKeysController`, and the worker schedules in spartan-api's CLAUDE.md. Check it there
  before changing it.
- `examples/` hold real API responses. Don't invent values, and never commit one from a signed-in user's private data
  (inventory, alerts, the bid list).
- The site is public: no keys, tokens or internal hostnames other than the public API URL.
- Feature branches and PRs only, squash-merged, as in every Spartan repo.
